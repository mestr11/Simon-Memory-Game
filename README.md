## Overview

* PWM

## Hardware used
* STM32 Nucleo F401RE
* 4 User Buttons
* 4 Colored LEDs (Red, Blue, Yellow, Green)
* 4 220 ohm resistors
* 1 passive buzzer 

## Tech Stack
* CMAKE project
* C Programming Language
* Visual Studio
* STM32 Extension pack
* HAL Abstraciton Libraries (provided by STM)
